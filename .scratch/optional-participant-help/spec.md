# 可选参与者现场求助

## 背景

现场多数问题通过举手即可解决。页面求助是低频辅助能力，不应默认占用参与者和 Staff 的主要界面。

## 决策

- `participantHelp` 活动开关默认关闭。
- 只有 Admin 可以在“活动设置”中开启或关闭。
- 关闭时，参与者不显示求助入口，API 拒绝创建新请求，Staff 不显示空求助指标或空队列。
- 关闭前已经创建的 active 请求仍对参与者和 Staff 可见，并允许 Staff 完成 `claim → resolve`，避免请求被遗失。
- 开启后沿用现有无自由文本的求助状态机与敏感信息边界。

## 验收

- 新活动和旧状态缺少该字段时均默认关闭。
- Admin UI 可开启并关闭该能力。
- API、参与者 UI、Staff UI 与 E2E 覆盖默认关闭、开启、关闭后处理存量请求。
- 不修改真实活动数据，不部署、不 push。
